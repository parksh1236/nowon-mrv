# 노원구 VWorld 태양광 건축 시뮬레이터 설계

## 1. 목적

기존 시스템과 분리된 웹 페이지에서 노원구의 기존 건물 또는 사용자가 만든 가상 건물을 대상으로 태양광 설치 가능면적과 예상 발전량을 사전 분석한다. 결과는 사업 후보지 비교와 초기 건축 검토를 위한 추정치이며 인허가, 구조 안전 검토, 실시설계를 대체하지 않는다.

## 2. 범위

### 포함

- VWorld WebGL 3D 지도에서 노원구 표시
- 주소 검색 또는 지도 클릭으로 기존 건물 선택
- 기존 건물의 외곽, 높이, 지붕면 자동 입력 시도
- 지도에서 가상 건물 외곽 작성
- 가상 건물의 높이, 층수, 지붕 형태, 경사, 방위 설정
- 옥탑, 냉각탑, 실외기 등 태양광 설치 제외 영역 직접 작성
- 개략 분석과 정밀 추정 분석
- 설치 가능면적, 패널 수, 설비용량, 월별·연간 발전량, 음영 손실 표시
- 입력값, 산정식, 가정값, 경고 표시
- 결과 CSV 내보내기와 브라우저 로컬 저장
- GitHub Pages 독립 배포

### 제외

- 전국 지역 지원
- 항공영상 기반 옥상 장애물 자동 판독
- 구조 안전성, 전기 계통연계, 경제성, 인허가 적합성 판정
- 사용자 계정, 서버 데이터베이스, 프로젝트 공동 편집
- 공인 설계도서 수준의 발전량 보증

## 3. 사용자 흐름

1. 사용자는 `기존 건물` 또는 `가상 건물` 분석을 선택한다.
2. 기존 건물은 주소 검색이나 지도 클릭으로 선택한다. 가상 건물은 노원구 내 부지에 외곽을 그린다.
3. 자동 수집된 건물값을 확인하거나 가상 건물의 높이와 지붕 조건을 입력한다.
4. 옥상 장애물과 안전 이격 영역을 제외 영역으로 그린다.
5. 모듈 효율, 패널 면적, 배치율, 시스템 손실률을 확인하거나 조정한다.
6. 개략 분석을 즉시 실행한다.
7. 필요하면 정밀 추정을 실행해 시간대별 태양 위치와 3D 음영을 반영한다.
8. 두 결과의 차이, 월별 발전량, 계산 근거와 경고를 확인하고 CSV로 내보낸다.

## 4. 화면 설계

`C. 분석 워크벤치` 단일 화면을 사용한다.

- 상단: 서비스명, 노원구 범위 안내, 주소 검색, 기존/가상 건물 전환, 개략/정밀 전환
- 왼쪽 패널: 건물·지붕·패널·손실률 입력과 분석 실행
- 중앙: VWorld 3D 지도, 건물 선택/작성, 제외 영역 작성, 패널 배치 및 음영 시각화
- 하단 또는 오른쪽 결과 영역: 설치 가능면적, 패널 수, 설비용량, 연간 발전량, 음영 손실, 월별 차트, 산정 근거
- 작은 화면: 입력 패널, 지도, 결과를 세로로 배치

키보드 조작, 명시적 입력 레이블, 충분한 색 대비, 색상 외 텍스트 상태 표시를 기본 접근성 조건으로 적용한다.

## 5. 기술 구조

별도 서버와 신규 프레임워크 없이 정적 HTML, CSS, JavaScript로 구성한다. VWorld WebGL 3D API 3.0이 지도와 3D 장면을 담당하고, 분석 계산은 브라우저에서 수행한다. 기존 저장소의 정적 배포 방식과 단일 페이지 패턴을 유지하되 독립 디렉터리에 둔다.

구성 단위는 다음과 같다.

- 화면: 모드 전환, 입력, 결과, 경고, CSV 다운로드
- 지도 어댑터: VWorld 초기화, 검색, 건물 선택, 도형 작성, 3D 객체 표시
- 분석 함수: 유효면적, 태양 위치, 경사면 일사량, 음영 표본, 발전량 계산
- 노원구 자료: 월별 대표 일사량과 기본 가정값
- 저장: `localStorage`에 마지막 입력과 분석 결과 저장

분석 함수는 지도 API와 분리된 순수 함수로 작성해 Node.js에서도 검사할 수 있게 한다. 한 구현만을 위한 별도 인터페이스나 서버 계층은 만들지 않는다.

## 6. 데이터와 계산

### 공통 입력

- 건물 외곽과 지붕 면적
- 지붕 형태, 경사, 방위각
- 제외 영역과 가장자리 안전 이격
- 패널 1장 면적과 정격용량
- 지붕 배치율
- 모듈 효율. 입력하지 않으면 패널 정격용량을 표준 일사강도 1 kW/㎡와 패널 면적으로 나눠 산출
- 인버터·배선·오염·온도 등을 합친 시스템 손실률

### 개략 분석

1. `유효면적 = 지붕면적 - 제외영역 - 안전이격영역`
2. `설치가능면적 = 유효면적 × 배치율`
3. `패널수 = floor(설치가능면적 / 패널 1장 면적)`
4. `설비용량 = 패널수 × 패널 1장 정격용량`
5. `월별 발전량 = 설치 패널면적 × 월별 경사면 일사량 × 모듈 효율 × (1 - 시스템 손실률)`로 계산한다.
6. 연간 발전량은 월별 발전량의 합계다.

### 정밀 추정

- 월별 대표일의 시간대별 태양 고도와 방위각을 계산한다.
- 지붕면을 표본 격자로 나누고 각 지점에서 태양 방향으로 광선을 투사한다.
- VWorld 장면의 지형과 주변 3D 건물에 막힌 표본을 음영으로 판정한다.
- 직달 성분에는 시간대별 음영률을 적용하고 산란 성분은 단순 등방성 모델로 계산한다.
- 월별 표본 결과를 월 일수로 환산해 정밀 추정 발전량과 음영 손실률을 산출한다.

브라우저 성능을 위해 정밀 추정의 기본 표본 간격과 시간 간격을 제한하고 사용자가 정확도 단계를 선택하게 한다. 결과에는 사용한 간격을 표시한다.

기상청의 위성 기반 태양광 기상자원지도는 2020~2024년 평균 자료, 2km 수평 해상도, 1시간 누적 수평면 일사량을 제공한다. 노원구에 필요한 값을 배포 전에 정적 JSON으로 전처리한다. 출처: <https://data.kma.go.kr/data/weatherResourceMap/selectWeatherResourceMapSlaNew.do?pgmNo=756&srt=ANN>

VWorld WebGL 3D 지도 API 3.0은 JavaScript 기반이며 Cesium 기능을 함께 활용할 수 있다. 출처: <https://www.data.go.kr/data/3073144/openapi.do>

## 7. 오류와 대체 흐름

- VWorld 키 없음 또는 도메인 불일치: 설정 방법을 표시하고 분석 실행을 막는다.
- VWorld 지도 로드 실패: 재시도 버튼과 원인을 표시하며 빈 결과를 정상값처럼 보여주지 않는다.
- 기존 건물 속성 누락: 사용자가 외곽, 높이, 지붕 조건을 직접 입력하도록 전환한다.
- 정밀 음영 계산 미지원 또는 실패: 개략 결과는 유지하고 정밀 결과만 실패로 표시한다.
- 노원구 경계 밖 입력: 분석을 막고 노원구 한정임을 표시한다.
- 잘못된 숫자, 교차하는 도형, 유효면적 0 이하: 해당 입력 가까이에 오류를 표시한다.
- 계산 결과에는 자동값, 사용자 입력값, 기본값을 구분해 표시한다.

## 8. 보안과 키 관리

로컬 개발용 키는 Git에 포함하지 않는 `config.local.js`에서 읽는다. 저장소에는 키 없는 예제 설정만 둔다. GitHub Pages의 브라우저용 VWorld 키는 최종 사용자에게 노출될 수 있으므로 비밀값으로 간주하지 않으며, VWorld 콘솔에서 실제 배포 도메인만 허용한다. 키를 로그, 오류 메시지, CSV에 기록하지 않는다.

## 9. 검증

- Node.js 기본 `assert`를 사용하는 계산 엔진 검사 1개를 둔다.
- 유효면적, 패널 수의 내림 처리, 손실률, 월·연간 합계, 입력 경계값을 검사한다.
- 브라우저에서 기존 건물 1건과 가상 건물 1건의 전체 흐름을 확인한다.
- VWorld 키 누락, 건물 데이터 누락, 노원구 경계 밖, 정밀 분석 실패 흐름을 확인한다.
- 모바일 너비에서 입력, 지도, 결과가 순서대로 보이고 키보드로 주요 기능을 사용할 수 있는지 확인한다.

## 10. 완료 조건

- 기존 건물과 가상 건물 모두 개략 분석을 완료할 수 있다.
- 지원되는 VWorld 3D 장면에서는 정밀 추정을 완료할 수 있고, 불가능할 때 명확한 오류가 표시된다.
- 결과에 설치 가능면적, 패널 수, 설비용량, 월·연간 발전량, 음영 손실과 계산 근거가 나온다.
- 계산 검사가 통과하고 대표 브라우저 시나리오가 동작한다.
- 기존 시스템과 분리된 URL로 GitHub Pages에 배포된다.

## 11. 향후 확장 조건

실사용 검증 후 필요성이 확인될 때만 전국 기상자료, 옥상 장애물 자동 판독, 구조·경제성 분석, 서버 프로젝트 저장과 보고서 PDF 생성을 추가한다.
