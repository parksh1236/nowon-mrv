# 솔라랩 가상 나무 음영 시뮬레이션 설계

## 1. 목적

VWorld 장면에 표시되지 않는 큰 나무를 사용자가 가상 3D 오브젝트로 배치하고, 시간별 그림자와 주변 지붕의 태양광 발전량 감소를 사전 비교한다. 결과는 현장 수목 측량이나 정밀 일조 검토를 대체하지 않는 설계 단계 추정치다.

## 2. 범위

### 포함

- 노원구 지도에서 여러 가상 나무 배치
- 각 나무의 높이와 수관 지름 입력
- 배치된 나무 선택과 삭제
- Kenney Nature Kit의 CC0 로우폴리 나무 모델 표시
- 기존 시간별 그림자 화면에서 나무 그림자 표시
- 정밀 분석에서 가상 나무 음영 반영
- 나무 반영 전·후 연간 발전량과 감소량 비교
- 프로젝트 저장·복원과 CSV 내보내기에 나무 정보 포함

### 제외

- 수종별 계절 변화, 낙엽, 가지 투과율
- 나무 성장 예측과 바람 애니메이션
- 직사각형·사용자 정의 장애물
- 실제 수목 자동 인식과 외부 수목 데이터 연동
- 개략 분석의 나무 음영 반영

첫 버전은 사용자가 요청한 핵심인 큰 나무 대체에 집중한다. 일반 사각 장애물은 나무 흐름이 현장에서 검증된 뒤 추가한다.

## 3. 사용자 흐름

1. 사용자가 `가상 나무` 영역에서 높이와 수관 지름을 입력한다.
2. `지도에 나무 배치`를 누른 뒤 지도에서 위치를 클릭한다.
3. 지도에 나무 모델이 즉시 나타나며 목록에 번호, 높이, 지름이 표시된다.
4. 같은 방식으로 여러 나무를 추가하거나 목록에서 선택한 나무를 삭제한다.
5. 시간별 그림자를 켜고 날짜와 시간을 움직여 나무와 건물 그림자를 확인한다.
6. 지붕을 선택하거나 작성한 뒤 정밀 분석을 실행한다.
7. 결과에서 나무 미반영 기준 발전량, 나무 반영 발전량, 감소량과 감소율을 비교한다.
8. 프로젝트를 저장하거나 CSV로 내보내면 나무 입력과 비교 결과도 포함된다.

## 4. 화면 설계

기존 입력 패널에 `가상 나무` 접이식 영역을 추가한다.

- 숫자 입력: 높이(m), 수관 지름(m)
- 버튼: `지도에 나무 배치`
- 목록: `나무 1 · 높이 12m · 지름 8m`와 삭제 버튼
- 배치 대기 중에는 지도 상태 문구로 다음 클릭이 나무 위치를 정한다는 사실을 알린다.
- 유효 범위는 높이 1~50m, 수관 지름 1~30m로 제한한다.
- 키보드 사용자를 위해 모든 입력에 레이블을 두고, 상태 변화는 기존 `role=status` 흐름을 재사용한다.

기존 시간별 그림자 패널과 지도 폭은 변경하지 않는다.

## 5. 기술 구조

새 프레임워크나 서버를 추가하지 않고 현재 정적 HTML과 JavaScript 구조를 유지한다.

- `solar/index.html`: 가상 나무 입력과 목록
- `solar/app.mjs`: 배치 상태, Cesium 모델 생성, 목록 조작, 분석 연결
- `solar/solar-core.mjs`: 저장 검증과 태양광선-원기둥 교차 판정 순수 함수
- `solar/solar-core.test.mjs`: 저장 호환성과 음영 판정 회귀 검사
- `solar/assets/tree.glb`: Kenney Nature Kit에서 선택한 CC0 저용량 모델
- `solar/assets/NOTICE.md`: 모델 출처와 CC0 기록

별도 장애물 클래스나 지도 추상화 계층은 만들지 않는다. 현재 `state`, `renderMapShapes`, `buildShadeSamples`, 프로젝트 직렬화 흐름에 최소 필드를 추가한다.

## 6. 데이터 구조와 호환성

프로젝트 상태에 다음 배열을 추가한다.

```js
trees: [
  {
    id: "tree-1",
    center: { lat: 37.654, lon: 127.056 },
    heightM: 12,
    crownDiameterM: 8
  }
]
```

- ID는 브라우저 세션에서 충돌하지 않는 문자열로 생성한다.
- 좌표는 노원구 경계 안이어야 한다.
- 저장된 이전 프로젝트에 `trees`가 없으면 빈 배열로 복원한다.
- 숫자가 유효 범위를 벗어나거나 좌표가 잘못된 나무는 프로젝트 전체를 깨뜨리지 않고 해당 항목을 제외한 뒤 경고한다.

## 7. 3D 표시와 그림자

각 나무는 지형 높이에 맞춰 배치한 Cesium 모델 엔티티 하나로 표시한다. 모델의 기준 높이를 측정해 `heightM`에 맞게 균일 배율을 적용한다. 수관 지름은 모델 표시 배율의 기준으로도 사용하되, 높이와 지름 비율이 모델 원본과 다르면 계산용 수관 크기를 우선하고 화면 모델은 높이에 맞춘다.

현재 `viewer.shadows`, `terrainShadows`, 장면 조명과 시계를 그대로 사용한다. 나무 모델은 그림자를 드리우도록 설정해 기존 날짜·시간 슬라이더에 즉시 반응한다. 모델 로드에 실패하면 위치와 크기를 보여주는 반투명 원기둥으로 대체하고 계산은 계속한다.

## 8. 발전량 계산

화면 모델의 세부 삼각형을 분석에 직접 사용하지 않는다. 각 나무를 지면에서 시작하는 불투명 수직 원기둥으로 단순화한다.

정밀 분석의 각 지붕 표본과 태양 방향 광선에 대해 다음 순서로 판정한다.

1. 기존 VWorld 장면 광선 판정으로 건물·지형 차폐를 구한다.
2. 동일 광선과 모든 가상 나무 원기둥의 교차를 순수 함수로 계산한다.
3. 둘 중 하나라도 차폐하면 해당 표본을 음영으로 처리한다.
4. 같은 조건에서 나무 교차만 제외한 기준 결과도 함께 집계한다.

결과에는 `나무 미반영 발전량`, `나무 반영 발전량`, `감소량(kWh/년)`, `감소율(%)`을 표시한다. 나무가 없으면 두 값은 같고 감소량은 0이다. 개략 분석은 3D 시간별 음영을 사용하지 않으므로 기존 결과를 유지하고 나무 비교는 정밀 분석에서만 제공한다.

## 9. 오류 처리

- 입력 범위 오류: 해당 입력 가까이에 메시지를 표시하고 배치를 시작하지 않는다.
- 노원구 밖 클릭: 나무를 만들지 않고 노원구 한정 안내를 표시한다.
- 모델 파일 실패: 원기둥 대체 표시 후 분석을 계속한다.
- 지형 높이 조회 실패: 지표 기준 위치로 표시하고 추정 배치라는 경고를 남긴다.
- 정밀 분석 취소 또는 실패: 기존 개략 결과와 저장된 나무를 유지한다.
- 나무가 많아지는 경우: 첫 버전은 최대 50개로 제한해 브라우저 정지 위험을 막는다.

## 10. 검증

- 광선이 원기둥의 옆면, 상단, 바깥을 통과하는 사례를 순수 함수로 검사한다.
- 여러 나무 중 하나만 광선을 막는 사례를 검사한다.
- 이전 형식 프로젝트가 빈 `trees`로 복원되는지 검사한다.
- 잘못된 나무 입력이 저장 복원을 중단시키지 않는지 검사한다.
- 나무가 없을 때 기존 정밀 분석 결과가 바뀌지 않는지 검사한다.
- 브라우저에서 배치 즉시 표시, 여러 개 배치, 삭제, 저장·복원, 시간 조절에 따른 그림자 이동을 확인한다.
- 대표 지붕에서 나무 반영 발전량이 기준 발전량보다 작거나 같은지 확인한다.

## 11. 완료 조건

- 노원구 지도에 높이와 수관 지름을 가진 나무를 여러 개 즉시 배치하고 삭제할 수 있다.
- 시간별 그림자를 켜면 나무 그림자가 날짜와 시간에 따라 움직인다.
- 정밀 분석 결과에 나무 반영 전·후 발전량과 차이가 표시된다.
- 저장·복원과 CSV에서 나무 정보가 유지된다.
- 기존 프로젝트 호환 검사와 음영 계산 검사가 통과한다.
- GitHub Pages에서 모델과 기능이 정상 로드된다.
