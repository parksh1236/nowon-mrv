# 지번 연결 및 월별 그래프 보완 — 2026-10-28

## 사용자 경로와 변경

- 지번 식별자가 없는 저장 표본을 클릭하면 Kakao 공식 주소 응답으로 시군구·법정동·본번·부번·산 여부를 확인한다.
- 주소가 정확히 일치하거나 표본 좌표 150m 이내의 유일한 지번일 때만 연결한다. 복수 지번·무관한 위치는 거부한다.
- 확인한 코드는 해당 표본 객체에서 재사용한다. 502개 표본 전체의 원본 파일을 일괄 수정한 것은 아니다.
- 주소 검색과 지도 점 클릭이 동일한 상세 조회 경로를 사용한다. 건축물대장과 에너지는 같은 지번과 산 여부를 사용한다.
- 월별 표를 처음부터 표시하고 받은 값부터 그래프를 갱신한다. 전기·가스의 최신 확보 월을 각각 표시한다.
- 미제공·조회 중·조회 실패·오류로 미조회 상태를 구분하며 0은 실제 반환값일 때만 0으로 남긴다.
- API 오류 시 이미 확보된 월은 유지하고 나머지 호출을 중단한다. 오류를 미제공으로 바꾸거나 그래프 전체를 숨기지 않는다.
- 건물/주소/지역 변경 후 이전 요청이 상세 패널을 덮어쓰지 못하도록 요청 식별자를 확인한다.
- 건축물대장 자료가 없다는 이유만으로 미등록 필지라고 단정하지 않는다.
- 지도 레이아웃 적용 전 준비 완료 문구가 나오는 타이밍도 조정했다.

API 키, 활용신청, 공급자 주소, 기존 MRV 작업은 변경하지 않았다.
