# 전기에너지 API 연결 보완 (2026-10-28)

요청: 기존 플랫폼의 전기에너지 API 재연결. 별도 MRV 작업은 변경하지 않는다.

## 검증

- 기존 키로 공공데이터포털 건물에너지 전기 API를 실제 호출: HTTP 200, resultCode 00.
- 노원구 상계동 701-1의 202601 전기 사용량: 414,111 kWh.
- Origin https://parksh1236.github.io 요청에 동일한 Access-Control-Allow-Origin 응답 확인.
- 동일 건물의 202607~202609는 정상 응답이나 totalCount 0. 최신 월 자료의 존재를 보장하지 않는다.
- node --test energy-api.test.mjs: 수정 전 2 통과/5 실패, 수정 후 7 통과/0 실패.
- 인라인 스크립트 vm.Script 문법 검사 통과.

## 보장하는 동작

1. 네트워크 실패 시 예외로 화면 조회가 중단되지 않고 연결 오류를 반환한다.
2. API 인증 오류와 HTTP 오류를 자료 없음으로 취급하지 않는다.
3. 실제 사용량 0은 정상 자료로 유지한다.
4. 빈 자료와 잘못된 숫자 응답을 구분한다.
5. 31일의 월 이동에도 전월부터 순서대로 조회한다.
6. 최신 월 탐색에서 연결 오류가 생기면 반복 호출을 중단하고 해당 오류를 화면에 표시한다.
7. API 호출은 15초로 제한한다.

테스트는 실제 HTML 함수를 VM에 로드해 모의 응답으로 수행한다. 전체 사이트 E2E와 커버리지 80%는 측정하지 않았으며, 실제 건물별 공개 범위·자료 공개 지연·다른 브라우저의 CORS 환경은 별도 확인이 필요하다. 인증키 값은 테스트·보고서에 복사하지 않았다.
