# 건물별 전기 지도 지역 확장 — 2026-10-28

## 요청 및 구현 범위

남양주시·용인시·강북구의 건물별 전기 표시와 데이터 누락 여부 확인.
기존 노원구·강남구 표본은 보존하고 5개 지역에서 현재 화면 API 조회를 제공한다.
용인시는 처인구(41461)·기흥구(41463)·수지구(41465)를 모두 포함한다.

지역 선택 → 새 지역 중심부 첫 페이지 자동 조회 → 지도 이동/확대 후
`현재 화면 조회 / 다시 조회` → `다음 50개 불러오기` 순서로 사용한다.
월 변경 후 다시 조회해야 하며 기존 점은 이전 월 자료임을 안내한다.
기본 월은 실제 API 자료가 확인된 2026년 4월이다. 최근 월은 공개 지연이 있을 수 있다.

## 데이터 경계

- 위치: 기존 공개 태양광 페이지의 브라우저용 VWorld 설정으로 LT_C_SPBD 조회.
  키 자체를 소스·테스트·이 문서에 복사하지 않는다.
- 사용량: 건물관리번호에서 시군구/법정동/산여부/본번/부번을 추출한 지번별 API 응답.
- 동일 필지 여러 동은 한 점으로 중복 제거. 동별·세대별 계량기 전수자료가 아니다.
- 현재 화면 위치 API 전체 건수와 불러온 건수, 필지 수를 구분한다.
- 0은 실제 값일 때만 유지한다. API 미제공·미조회·오류를 0으로 대체하지 않는다.
- 동일 지번 복수자료는 첫 행만 임의로 표시하지 않고 확인 필요 오류로 남긴다.
- 현재 화면의 위치 페이지를 모두 읽어도 지역 전체 또는 모든 계량기를 읽었다는 의미가 아니다.
- 가스는 일괄 수집하지 않으며 미조회로 표시. 건물 선택 후 월별 조회 경로는 유지한다.
- 429는 최대 3회 시도. 공공데이터 API는 공용 순차 큐에서 응답 후 최소 650ms 간격을 둔다.
  제한이 계속되면 오류·미조회를 보존한다.

## 자체 점검

종합 4.0/5. 중대한 미해결 구현 오류 없음.

- 정확성 4: 실제 3지역 API·브라우저 검증. 모든 지역·월은 확인하지 않아 전수 제공으로 표현하지 않는다.
- 완결성 4: 요청 지역/용인 3구/누락 상태 구현. 지역 전수 수집은 별도 서버 수집 작업이 필요하다.
- 명확성 4: 월·범위·상태별 건수 표시. 위치 수와 필지 수가 달라 중복 안내를 유지한다.
- 실행가능성 4: 첫 페이지 자동 조회와 다음 페이지 버튼. 지속적 API 제한 시 나중에 재조회가 필요하다.
- 간결성 4: 핵심은 별도 모듈. 기존 지도와의 통합 코드 일부는 인라인에 남아 있다.

개선 우선순위: 전수 수집 요청 시 서버 수집·재개 저장 설계, 전체 페이지 수집 대조,
모바일/접근성 실측. 현재 화면 조회를 전수 수집으로 홍보하지 않는다.
사용자가 동의할 평가인지: 범위를 공개하고 실제 세 지역 표시를 검증했으므로 그렇다.
